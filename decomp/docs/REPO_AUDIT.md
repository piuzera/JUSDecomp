# Repository audit — public publishing (v0.1.0)

Pre-release audit performed 2026-08-24. Policy: publish only original code,
docs, scripts, configs, and reverse-engineered metadata. Never publish game
binaries, ROM-derived assets, personal saves, or session artifacts.

## 1. Headline numbers

| Item | Count |
|---|---|
| Files tracked in the old history (9 local commits) | 1325 |
| Artifacts among them (`.dtx` extractions, saves, logs, coverage, bins, screenshots, patched ROM) | ~1080 |
| Files that will be published after the history reset | ~245 (see §3) |
| Secrets/credentials found (password/api-key/token scans) | **0** |
| Git remotes ever configured | none (history never pushed) |

## 2. Git history decision

The old history's final "Version 0.1" commit tracked personal `.sav` files, a
patched `jus-mod.nds`, RAM dumps, logs, coverage captures, and 901 extracted
`.dtx` assets. Since the repository was never pushed, history is rebuilt:
old commits are preserved in the local branch `backup/pre-v0.1`, and the
public repo starts with one clean initial commit + tag `v0.1.0`.

## 5. Sensitive / legal findings

1. **Personal saves** (13 `.sav`) were tracked in old history — resolved by
   history reset (backup branch stays local only).
2. **Patched ROM `jus-mod.nds`** was tracked — resolved likewise.
3. **No secrets**: token/password/key scans across all config/script/docs
   files returned zero hits. The only personal datum in git metadata was the
   owner's commit identity, which the fresh initial commit will keep
   (intended authorship).
4. **Local `ndsrecomp` modifications** (18 files, +581 lines) exist only in
   the gitignored clone — now exported and verified as
   `patches/ndsrecomp/0001-jus-runner-modifications.patch` against upstream
   base `e9b530a0e08fe7c270ed97737b1c1495de9d1587`.
5. `data/koma_external.csv` carries the owner's own "Jump Database"
   enrichment (English names etc.) — original compilation work, no game
   assets, kept intentionally.
